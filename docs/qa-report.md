# تقرير قبول النسخة المستقلة

**التاريخ:** 29 أغسطس 2026
**الحكم:** ناجح؛ النسخة جاهزة للنشر.

## النتيجة

يفتح الموقع مباشرة بلا كلمة مرور أو تسجيل دخول. تبدأ الرحلة من أنواع اللجان، ثم الخطة الزمنية، ثم قائمة المهام. لا تظهر أقسام أو أسماء أشخاص أو قوالب أو روابط إلى منصات خارجية.

أعيد ضبط التسلسل البصري ليكون مدمجًا: العنوان في سطر واحد، والمؤشران داخل المقدمة، وأربع بطاقات لجان في الصف على سطح المكتب، وخط زمني أصغر، وبطاقات مهام مختصرة. أزيل قسم طريقة الاستخدام والمعلومات المتكررة.

## اختبارات القبول

| المجال | النتيجة |
|---|---|
| البيانات | 268 سجلًا مصدريًا تختزل إلى 64 مهمة موحدة |
| أنواع اللجان | 11 نوعًا، وكل نوع يظهر مرة واحدة |
| الخطة الزمنية | التهيئة، 14 أسبوعًا، وفترة الاختبارات |
| عرض المهمة | المطلوب، الدور الوظيفي، الموعد، ثلاث خطوات، شاهد واحد، وأربعة مكونات |
| الساعات المكتبية | الجدول العام المنشور هو الشاهد الوحيد |
| الدخول | لا شاشة دخول ولا كلمة مرور ولا تخزين لحالة دخول |
| الاستقلال | لا روابط خارجية ولا ربط أو حالة تسليم خارج الموقع |
| ملف التقويم | تنزيل `.ics` حسب اللجنة والزمن، مع تنبيه قبل الموعد بيوم |
| التحقق الآلي | `npm run check:data` ناجح في 893 تأكيدًا |
| البناء | `npm run build` ناجح بلا تحذير حجم |

## فحص المتصفح

| المقاس | ما تم التحقق منه | النتيجة |
|---|---|---|
| 1440×900 | أول الشاشة، أنواع اللجان، 64 مهمة، البحث، والفلاتر | 8 بطاقات لجان كاملة والبطاقات الـ11 حاضرة في أول شاشة؛ لا تمرير أفقي |
| 390×844 | الصفحة الرئيسية وأهداف اللمس | تظهر بطاقة لجنة كاملة في أول شاشة؛ جميع الأهداف التفاعلية 44 بكسل على الأقل |
| 320×568 | نافذة المهمة وأداة تحميل التقويم | داخل الشاشة بتمرير رأسي طبيعي؛ لا تمرير أفقي |

اختُبر فتح نافذة المهمة وإغلاقها واستعادة التركيز إلى زرها. وتظهر مهمة الساعات المكتبية بثلاث خطوات، ودور «منسق أعمال اللجنة»، وشاهد واحد بأربعة مكونات.

اختُبر كذلك اختيار لجنة الإرشاد الأكاديمي مع «الفصل كاملًا»؛ جهزت الواجهة ملفًا من 7 مواعيد باسم عربي واضح، وبقيت الصفحة في موضعها بعد التنزيل.
