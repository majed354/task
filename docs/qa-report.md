# تقرير قبول النسخة المبسطة

**التاريخ:** 22 أغسطس 2026

**الفرع:** `codex/role-based-evidence-only`
**الحكم:** ناجح؛ لا توجد ملاحظة P0 أو P1.

## النتيجة

تعرض البوابة الآن أقل قدر لازم لإنجاز المهمة: المطلوب، الدور الوظيفي، الموعد، ثلاث خطوات، شاهد واحد، وأربعة مكونات قصيرة للشاهد. لا تعرض أسماء أشخاص أو قوالب أو روابط تنزيل قوالب.

## اختبارات القبول

| المجال | النتيجة |
|---|---|
| بيانات المهام | 268 مهمة، 64 نوعًا مركزيًا، و19 دليلًا مستخدمًا |
| الإحالات | 268/268؛ كل إحالة تحتوي `guideId` فقط |
| الشواهد | شاهد واحد وأربعة مكونات لكل دليل |
| الأدوار | «منسق أعمال اللجان بالقسم» و«رئيس القسم» بدل الأسماء الشخصية |
| القوالب | لا تنقل أو عداد أو زر تنزيل أو رابط `/templates` في الواجهة أو الحزمة |
| الساعات المكتبية | ثلاث خطوات، والشاهد الوحيد هو الجدول العام المنشور بمكوناته الأربعة |
| التحقق الآلي | `npm run check:data` ناجح في 924 تأكيدًا |
| البناء | `npm run build` ناجح |

## فحص الأسماء والقوالب

- لم يظهر أي من الأسماء الشخصية الثمانية السابقة في `App.tsx` أو عقد البيانات التشغيلي أو كتالوج المهام أو حزمة `dist`.
- لم تظهر عبارات «تحميل القالب» أو «ابدأ بهذا القالب» أو «قوالب مرافقة» أو رابط يؤدي إلى `/templates`.
- بقيت ملفات Office السابقة داخل `public/templates` كأرشيف داخلي غير ظاهر وقابل للرجوع؛ ولا ترتبط بأي مهمة.
