# طلب تفعيل لوحة متابعة اللجان

إلى مسؤول Microsoft 365 بجامعة الطائف: نحتاج تسجيل تطبيق SPA أحادي المستأجر لقراءة سجل مهام اللجان ومجلداته من موقع قادة كلية الشريعة والأنظمة، وعرض المؤشرات للأعضاء المصرح لهم بعد دخولهم بحساب الجامعة.

| الإعداد | القيمة المطلوبة |
| --- | --- |
| اسم مقترح | لوحة متابعة لجان كلية الشريعة والأنظمة |
| المستأجر | Taif University — `e26bab4b-97e6-4754-b163-60f8237e8531` |
| نوع التطبيق | Single-tenant SPA، بلا سر عميل |
| Redirect URI | `https://shari3ahtask.netlify.app/` |
| Microsoft Graph | Delegated `Sites.Selected` |
| الموقع المسموح | `https://taifedusa.sharepoint.com/sites/msteams_3b4354` |
| تعيين الموقع | `read` لهذا التطبيق على الموقع المحدد فقط |

يرجى إعادة **Application (client) ID** بعد التسجيل والتعيين. يقرأ التطبيق قائمة «سجل مهام اللجان 1448» ومكتبة المستندات في الموقع المذكور؛ لا يطلب الكتابة أو صلاحية على مواقع أخرى. تظل صلاحية المستخدم نفسه مطلوبة عند تسجيل الدخول. لن تظهر الأرقام في Netlify حتى تُضبط هوية التطبيق ويُختبر الاتصال.

المرجع: [Microsoft Graph Selected permissions](https://learn.microsoft.com/en-us/graph/permissions-selected-overview).
