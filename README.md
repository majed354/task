# بوابة أعمال اللجان

مرجع عربي تنفيذي لأعمال لجان كلية الشريعة والأنظمة. تجمع البوابة بين جدول المهام، ودليل التنفيذ، والشاهد المطلوب ومكوناته، وقواعد التسمية والاعتماد، بينما يبقى التسليم النهائي داخل SharePoint.

## محتوى المنظومة

- 268 مهمة لأربعة أقسام، مرتبطة بـ64 نوع مهمة مركزيًا.
- 19 دليل تنفيذ مركزيًا، مع ربط صريح لكل مهمة بدليلها وشاهد واحد ومكوناته العملية.
- شاهد واحد لكل مهمة، مع 3–4 مكونات قصيرة توضّح ما يجب أن يحتويه.
- بحث وفلاتر حسب القسم واللجنة والأسبوع والدليل والمخرج وحالة الموعد.
- عرض مختصر لكل مهمة: المطلوب، المنفذ، الموعد، ثلاث خطوات، شاهد واحد، ومكونات الشاهد.
- فصل واضح بين حالة الموعد المحسوبة وحالة التسليم الفعلية؛ تبقى الأخيرة «بانتظار الربط» حتى وصول بيانات حية من SharePoint.

للساعات المكتبية دليل مستقل مرتبط بأربعة سجلات `T001`: يحدد العضو ساعاته في جدوله الأسبوعي ويوقع، ويجمع المنسق الجداول ويتحقق من اكتمالها، ثم يعتمد الجدول العام وينشر. الجدول المنشور هو الشاهد الوحيد، وتوضح المهمة مكونات الجدول المطلوبة دون فرض قالب.

## التقويم المرن

يقرأ التطبيق الفصول والأحداث من ملف إعداد واحد: `src/config/academicCalendar.json`. يدعم الفصل الأول والثاني والصيفي، وأسبوع التهيئة، والتوقفات، وأيام العمل، ومهلة السماح، ومنع بدء أسبوع تشغيلي داخل الاختبارات.

تبدأ أعمال اللجان للفصل الأول يوم الأحد 30 أغسطس 2026، ويبدأ أول أسبوع تشغيلي يوم الأحد 6 سبتمبر. لكل حدث مصدره وجهة الإصدار وحالة التحقق وتاريخ الاطلاع وموعد المراجعة.

## أرشيف القوالب السابق

أُزيلت القوالب من الواجهة ومن رحلة إنجاز المهمة. بقيت الملفات السابقة في `public/templates` كأرشيف داخلي قابل للرجوع، لكنها غير مرتبطة بأي مهمة ولا يراها المستخدم في البوابة.

- Word: محضر اجتماع، خطة تشغيلية، تقرير إنجاز وتحليل، تقرير نشاط وقياس أثر، معالجة ملاحظة وفرصة تحسين، والتقرير الختامي.
- Excel: متابعة القرارات، فحص جودة الملف، فحص الخطط العلمية، مؤشرات الأداء، تحليل الاستبانة، سجل الأدلة، إعداد الجدول الدراسي، وجاهزية الاختبارات.

تحتوي ملفات Word على إرشادات وحقول تحليل واعتماد وقائمة تحقق. وتحتوي ملفات Excel على أوراق إرشاد وإدخال وملخص، وصيغ محمية من الفراغ والقسمة على صفر. توثق [مواصفة القوالب](docs/template-specification.md) البنية الفعلية وخطة الفحص.

## التشغيل والتحقق

```bash
npm install
npm run check:data
npm run build
npm run dev
```

يفحص `check:data` تغطية المهام والأدلة، واستقلال إحالات المهام عن القوالب، ووجود شاهد واحد مع 3–4 مكونات عملية لكل دليل، وسلامة أرشيف القوالب غير الظاهر، وبنية التقويم، واستقلال لجان فحص الخطط، وغياب البريد وأرقام الجوال من بيانات البوابة.

## ملاحظات تشغيلية

- شاشة الدخول الحالية تقبل `1429` أو `١٤٢٩`. هي بوابة عرض وليست مصادقة مؤسسية.
- مسارات المجلدات الظاهرة مقترحة وغير معتمدة حتى يكتمل ربط SharePoint.
- لا تعرض المنظومة نسب إنجاز تجريبية أو تستنتج تسليمًا مبكرًا من الموعد وحده.
- المشروع مهيأ لـNetlify، لكن نشر هذه النسخة أو دمجها في `main` يتطلب موافقة صريحة منفصلة.
