# بوابة أعمال اللجان

بوابة عربية تعرض التقويم التشغيلي للجان، والمهام التفصيلية، وطريقة الإنجاز، وقوالب Word وExcel الجاهزة. يبقى SharePoint مساحة العمل والتسليم النهائي، وتبقى Power BI لوحة الإنجاز بعد ربط البيانات الفعلية.

## التقويم الديناميكي

- مرجع العام 1448-1449هـ هو [التقويم الجامعي الرسمي لجامعة جدة](https://www.uj.edu.sa/ar/التقويم-الجامعي)، إلى حين صدور التقويم التفصيلي لجامعة الطائف.
- الفصل الأول يبدأ في `2026-08-23`، ويخصص الأسبوع الأول للتهيئة؛ لذلك تبدأ مهام اللجان الإلزامية في `2026-08-30`.
- يحسب الموقع تلقائيًا الأيام المتبقية، والأسبوع الحالي، وموعد التسليم الأساسي، ومهلة السماح البالغة سبعة أيام.
- تُتجاوز الإجازات الممتدة عند بناء الأسابيع التشغيلية، بينما تظهر الإجازات القصيرة داخل بطاقة الأسبوع.
- لا توجد نسب إنجاز تجريبية؛ لا تظهر حالة الإنجاز الفعلية إلا بعد ربط SharePoint.

إضافة فصل قادم لا تتطلب تغيير المهام أو الواجهة. أضف سجلًا جديدًا إلى `src/academicCalendar.ts` يتضمن بداية الفصل ونهايته وفترة الاختبارات والإجازات، وسيظهر تلقائيًا في محدد الفصول ويستخدمه العدّاد.

## القوالب

المجلد `public/templates` يحتوي سبعة قوالب قابلة للتنزيل من داخل البوابة:

- محضر اجتماع لجنة.
- تقرير إنجاز وتحليل مهمة.
- خطة تشغيلية للجنة.
- تقرير نشاط وقياس أثر.
- مصفوفة متابعة القرارات.
- قائمة فحص جودة الملف.
- نموذج فحص الخطط العلمية، مع تخصصات مستقلة للقراءات والدراسات القرآنية والفقه وأصول الفقه.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على Netlify

المشروع مهيأ عبر `netlify.toml`. عند ربط المستودع يكتشف Netlify أمر البناء `npm run build` ومجلد النشر `dist` تلقائيًا.

تتضمن النسخة الحالية شاشة دخول تقبل الرمز `1429` بالأرقام العربية أو الإنجليزية. هذه حماية عرض فقط وليست مصادقة مؤسسية؛ تستبدل بتسجيل الدخول الجامعي عند الإطلاق الرسمي.
