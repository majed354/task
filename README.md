# بوابة أعمال اللجان

مرجع عربي تنفيذي لأعمال لجان كلية الشريعة والأنظمة. تجمع البوابة بين جدول المهام، ودليل التنفيذ، والقالب المناسب، وقواعد التسمية والأدلة والاعتماد، بينما يبقى التسليم النهائي داخل SharePoint.

## محتوى المنظومة

- 268 مهمة لأربعة أقسام، مرتبطة بـ64 نوع مهمة مركزيًا.
- 18 دليل تنفيذ مركزيًا، مع ربط صريح لكل مهمة بالدليل والقالب الأساسي والقوالب المرافقة.
- 14 قالبًا عربيًا RTL: ستة ملفات Word وثمانية ملفات Excel.
- بحث وفلاتر حسب القسم واللجنة والأسبوع والدليل والمخرج وحالة الموعد.
- بطاقة «المهمة التالية» وتوقيت حي، وتفاصيل المسؤوليات والمدخلات والخطوات والأدلة ومعايير القبول.
- فصل واضح بين حالة الموعد المحسوبة وحالة التسليم الفعلية؛ تبقى الأخيرة «بانتظار الربط» حتى وصول بيانات حية من SharePoint.

## التقويم المرن

يقرأ التطبيق الفصول والأحداث من ملف إعداد واحد: `src/config/academicCalendar.json`. يدعم الفصل الأول والثاني والصيفي، وأسبوع التهيئة، والتوقفات، وأيام العمل، ومهلة السماح، ومنع بدء أسبوع تشغيلي داخل الاختبارات.

لا يوجد وقت إعداد هذه النسخة تقويم بكالوريوس 1448هـ منشور ومتحقق لجامعة الطائف؛ لذلك تحمل البيانات وسم:

> تقويم جامعي رسمي مقارن — بانتظار تقويم جامعة الطائف

لكل حدث مصدره وجهة الإصدار وحالة التحقق وتاريخ الاطلاع وموعد المراجعة. راجع [البحث الرسمي](docs/official-research.md) قبل اعتماد التواريخ محليًا.

## القوالب

توجد الملفات في `public/templates`:

- Word: محضر اجتماع، خطة تشغيلية، تقرير إنجاز وتحليل، تقرير نشاط وقياس أثر، معالجة ملاحظة وفرصة تحسين، والتقرير الختامي.
- Excel: متابعة القرارات، فحص جودة الملف، فحص الخطط العلمية، مؤشرات الأداء، تحليل الاستبانة، سجل الأدلة، إعداد الجدول الدراسي، وجاهزية الاختبارات.

تحتوي ملفات Word على إرشادات وحقول تحليل واعتماد وقائمة تحقق. وتحتوي ملفات Excel على أوراق إرشاد وإدخال وملخص، وصيغ محمية من الفراغ والقسمة على صفر. توثق [مواصفة القوالب](docs/template-specification.md) البنية الفعلية وخطة الفحص.

## التشغيل والتحقق

```bash
npm install
npm run check:data
npm run build
npm run dev
```

يفحص `check:data` تغطية المهام والأدلة والقوالب، وبنية التقويم، واستقلال لجان فحص الخطط، ووجود لجنة الجداول، وغياب البريد وأرقام الجوال من بيانات البوابة.

## ملاحظات تشغيلية

- شاشة الدخول الحالية تقبل `1429` أو `١٤٢٩`. هي بوابة عرض وليست مصادقة مؤسسية.
- مسارات المجلدات الظاهرة مقترحة وغير معتمدة حتى يكتمل ربط SharePoint.
- لا تعرض المنظومة نسب إنجاز تجريبية أو تستنتج تسليمًا مبكرًا من الموعد وحده.
- المشروع مهيأ لـNetlify، لكن نشر هذه النسخة أو دمجها في `main` يتطلب موافقة صريحة منفصلة.
