# بوابة أعمال اللجان

بوابة عربية تعرض الخطة الأسبوعية للجان، شرح المهام، والقوالب المعتمدة. يبقى SharePoint مساحة العمل والتسليم النهائي.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على Netlify

المشروع مهيأ عبر `netlify.toml`. عند ربط المستودع يكتشف Netlify أمر البناء `npm run build` ومجلد النشر `dist` تلقائيًا.

تتضمن النسخة التجريبية شاشة دخول تقبل الرمز `1429` بالأرقام العربية أو الإنجليزية. هذه الحماية مناسبة للعرض التجريبي فقط، وتستبدل بتسجيل الدخول الجامعي عند الإطلاق المؤسسي.
