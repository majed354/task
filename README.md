# دليل أعمال اللجان

موقع عربي مستقل يوضح أعمال لجان كلية الشريعة والأنظمة بطريقة مباشرة. يفتح الموقع بلا تسجيل دخول، ويبدأ من نوع اللجنة ثم يعرض موقعها في الخطة الزمنية ومهامها.

## محتوى الموقع

- 11 نوع لجنة وجهة عمل.
- 64 مهمة موحدة بلا تكرار بين الأقسام.
- خطة زمنية تشمل التهيئة و14 أسبوعًا وفترة الاختبارات.
- بحث وتصفية حسب نوع اللجنة والمحطة الزمنية.
- تنزيل تقويم بصيغة `.ics` لأي لجنة وأي أسبوع أو للفصل كاملًا، مع تنبيه قبل الموعد بيوم.
- لكل مهمة: المطلوب، الدور الوظيفي، الموعد، ثلاث خطوات، شاهد واحد، ومكونات الشاهد.
- لا أسماء أشخاص، ولا أقسام، ولا قوالب تنزيل، ولا اتصال بمنصة أخرى.

في مهمة الساعات المكتبية يحدد كل عضو ساعاته في جدوله الأسبوعي ويوقعه، ثم يجمع منسق أعمال اللجنة الساعات في جدول عام ويتحقق من اكتمالها وينشره. الجدول العام المنشور هو الشاهد الكافي.

## التقويم

تبدأ أعمال اللجان للفصل الأول يوم الأحد 30 أغسطس 2026، ويبدأ الأسبوع التشغيلي الأول يوم الأحد 6 سبتمبر. تحفظ إعدادات الفصول والمحطات في `src/config/academicCalendar.json`.

يتوافق ملف التقويم مع Apple Calendar وOutlook، ويمكن استيراده في Google Calendar.

## التشغيل والتحقق

```bash
npm install
npm run check:data
npm run build
npm run dev
```

يتحقق `check:data` من اختزال السجلات المصدرية إلى 64 مهمة، واتساق أنواع اللجان والمواعيد، واكتمال أدلة التنفيذ والشواهد، وغياب الدخول والأقسام والروابط الخارجية من الواجهة.

للتفاصيل التشغيلية راجع [دليل التنفيذ](docs/task-execution-guide.md) و[تقرير ضمان الجودة](docs/qa-report.md).
