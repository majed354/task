# دليل أعمال اللجان

موقع عربي لكلية الشريعة والأنظمة بقسمين: «دليل أعمال اللجان» العام و«لوحة المتابعة» التي تقرأ السجل التشغيلي من SharePoint بعد دخول العضو بحساب الجامعة.

## محتوى الموقع

- 9 لجان في العرض؛ فُصلت أعمال الجودة والاعتماد إلى لجنة لبرامج البكالوريوس ولجنة لبرامج الدراسات العليا.
- 85 مهمة مجدولة؛ منها 14 مهمة جودة أساسية تتكرر لكل مسار، ومراجعتان لموقع النشاط العلمي في منتصف الفصل ونهايته، مع بيان نطاق كل مهمة.
- توزيع وظيفي متوازن: 6 مهام للإرشاد، و8 للأنشطة والشؤون الطلابية، و9 للعلاقات العامة والإعلام.
- عرض تفاعلي لأقرب 10 مهام في صفوف مختصرة تفتح تفاصيل المهمة بالنقر.
- خطة زمنية تشمل التهيئة و14 أسبوعًا وفترة الاختبارات.
- بحث وتصفية حسب نوع اللجنة والمحطة الزمنية.
- تنزيل تقويم بصيغة `.ics` لأي لجنة وأي أسبوع أو للفصل كاملًا، مع تنبيه عند بداية المهمة وتنبيه آخر قبل التسليم بيوم.
- لكل مهمة: المطلوب، الدور الوظيفي، الموعد، ثلاث خطوات، شاهد واحد، ومكونات الشاهد.
- الدليل العام لا يعرض أسماء أشخاص أو أقسام أو قوالب تنزيل.

## لوحة المتابعة

تظهر في `/?view=dashboard`. تقرأ لوحة المتابعة قائمة «سجل مهام اللجان 1448» في موقع قادة الكلية، وتعرض الإجمالي والإنجاز والتعثر بحسب القسم واللجنة. المهمة متأخرة إذا تجاوزت موعد تسليمها ولم تكتمل، أو إذا سُجلت حالتها «متعثر». يفحص الموقع مجلدات المهام في `أعمال اللجان/دليل مهام اللجان` ويعرض عدد المجلدات التي تحوي عناصر إضافية، دون اعتبار وجود ملف دليلًا على اكتمال المهمة.

بيانات SharePoint لا تُضمّن في ملفات الموقع ولا تُحفظ في Netlify. تُقرأ في متصفح العضو بتصريح Microsoft Graph مفوض، ويظل الوصول خاضعًا لصلاحيات موقع قادة الكلية.

لتفعيل القراءة، يسجل مسؤول Microsoft 365 تطبيق SPA في مستأجر الجامعة مع عنوان إعادة التوجيه `https://shari3ahtask.netlify.app/` والصلاحية المفوضة `Sites.Selected`، ثم يمنح التطبيق دور `read` على موقع `https://taifedusa.sharepoint.com/sites/msteams_3b4354` فقط. بعد إعادة معرّف التطبيق تُضبط متغيرات البناء `VITE_ENTRA_CLIENT_ID` و`VITE_ENTRA_TENANT_ID` في Netlify ويُعاد النشر. لا يحتاج التطبيق إلى سر عميل. انظر [طلب تفعيل ربط SharePoint](docs/sharepoint-connection-request.md).

في مهمة الساعات المكتبية يحدد كل عضو ساعاته في جدوله الأسبوعي ويوقعه، ثم يجمع منسق أعمال اللجنة الساعات في جدول عام ويتحقق من اكتمالها وينشره. الجدول العام المنشور هو الشاهد الكافي.

## مهام تغطية أدلة الدراسة الذاتية

أضيفت 12 مهمة موحدة تنتج الأدلة التي لا يثبتها إلا عمل لجنة — محضر أو قرار أو مراجعة فنية أو جولة أو تحليل معتمد. واستُبعد ما تنتجه المنظومة (الاستبانات وتحليلها والبيانات الإحصائية) وما ينتجه عضو هيئة التدريس بنفسه، فأُدرجت مراجعته لا إنتاجه.

وعُدّلت خطوات سبع مهام قائمة بدل استحداث مهام جديدة لها: قياس مؤشرات الأداء (يضيف المقارنة المرجعية)، ورفع متطلبات الاعتماد (يضيف متابعة التوصيات السابقة وإقفالها)، ومتابعة رفع تقارير المقررات (تتحول إلى مراجعة فنية واستخلاص توصيات مشتركة)، والمراجعة الشاملة للبرامج (تضيف المقارنة المرجعية للمنهج)، وحصر الاحتياج التدريسي (يضيف دراسة كفاية الأعداد والتخصصات)، ومتابعة سير الاختبارات (تضيف ضوابط النزاهة الأكاديمية)، ومبادرات الشراكة المجتمعية (تمتد من الاقتراح إلى التنفيذ وقياس الأثر).

توزيع المهام الجديدة على اللجان القائمة بلا استحداث لجنة: الجودة والاعتماد 5، تطوير المناهج 3، الإرشاد الأكاديمي 3، الاختبارات والنتائج 1. ولجنتا الجداول والأنشطة الطلابية استوعبتا ما يخصهما داخل مهامهما القائمة.

## التقويم

تبدأ أعمال اللجان للفصل الأول يوم الأحد 30 أغسطس 2026، ويبدأ الأسبوع التشغيلي الأول يوم الأحد 6 سبتمبر. تحفظ إعدادات الفصول والمحطات في `src/config/academicCalendar.json`.

يكون «الفصل كاملًا» هو النطاق الافتراضي في الخطة وقائمة المهام وتحميل التقويم، مع بقاء الأسبوع الحالي مميزًا بصريًا. يتوافق ملف التقويم مع Apple Calendar وOutlook، ويمكن استيراده في Google Calendar.

## التشغيل والتحقق

```bash
npm install
npm run check:data
npm run build
npm run dev
```

يتحقق `check:data` من سلامة سجلات الدليل وتوزيعها واتساق مواعيدها واكتمال أدلة التنفيذ والشواهد، ومن ظهور قسمي الموقع وربط لوحة المتابعة بمصدر SharePoint.

للتفاصيل التشغيلية راجع [دليل التنفيذ](docs/task-execution-guide.md) و[تقرير ضمان الجودة](docs/qa-report.md).
